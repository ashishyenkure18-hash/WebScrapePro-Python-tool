# WebScrapePro – Python Web Scraping & Data Extraction Tool

## 1. Introduction
WebScrapePro is a beginner-friendly Python application that fetches
publicly accessible webpages and extracts headlines, quotes, and text
using **Requests** and **BeautifulSoup4**. Results can be saved as JSON
or TXT files.

## 2. Objectives
- Demonstrate HTTP request handling with timeouts & error handling.
- Demonstrate HTML parsing with BeautifulSoup CSS selectors.
- Practice data cleaning, de-duplication, and formatting.
- Teach responsible and legal scraping.

## 3. Technologies Used
- Python 3
- Requests
- BeautifulSoup4
- JSON / TXT storage
- VS Code
